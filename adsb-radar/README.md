# ADS-Bレーダー

頭上を飛ぶ飛行機を液晶にレーダー表示する装置です（ESP32-C3・3Dプリントケース）。羽田運用ボードと組み合わせて使います。

| フォルダ | 中身 |
| --- | --- |
| `firmware/adsb_radar/` | レーダー本体のプログラム |
| `firmware/lcd_test/` | 液晶の点検用プログラム |
| `stl/` | ケースの3Dプリント部品（ふた・正面の試し刷り・つまみ・スタンド） |
| `step/` | 同じ部品のSTEP（正面ケースを含む） |
| `design/` | ケースの設計スクリプト |
| `wiring/` | 回路図とユニバーサル基板の配置図 |
| `images/` | ケースの完成イメージ |
| `材料リスト.md` | 必要な部品 |

## Wi-Fiの設定

Wi-Fiの名前とパスワードは公開していません。`firmware/adsb_radar/config.example.h` をコピーして `config.h` という名前にし、`YOUR_SSID` と `YOUR_PASSWORD` を書き換えてから書き込んでください。
