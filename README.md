# 羽田空港 運用ボード（第4版：ADS-B レーダーと合体）

3mm の黄ボードをレーザーで切って重ねた羽田空港の模型です。滑走路の端に在庫の LED を埋め込み、いま使われている滑走路と向きを光で表示します。
飛行機が離陸するたびに、その滑走路の LED（黄→赤）が速く点滅します。

右上には ADS-B レーダーの本体を裏ぶたなしでのせます。その下の L1・L2 に穴をあけ、裏に貼った 3D プリントのトレーにレーダーの ESP32-C3・ブザー・電源分配基板をしまいます。
運用ボード（LED）の ESP32-C3 と抵抗基板は、第3版で作ったケース（case.stl）に入れて、第3版と同じ位置（島の真ん中の下）に貼ります。
レーダーの 2 つのボタン（表示・明るさ）は海の板の上に移しました。

- `3Dモデル.html`：組み立てた状態の 3D モデル（ブラウザで開く）。北風運用・南風運用の光り方を切り替えられる
- `laser/`：レーザー加工の図面（SVG と DXF）
- `stl/`・`step/`：3D プリント部品（トレー・運用ボードのケース・脚・管制塔・ボタン穴の栓）
- `laser/check_report.md`：図面のチェック結果
- `design/`：設計のもと。`python3 board.py`（図面）、`python3 case3d.py`（3D プリント部品）

## 形のもと

- 空港の輪郭・ターミナル（第1・第2・第3）・エプロン・誘導路・滑走路・管制塔の位置、建物の輪郭（`design/osm_buildings.txt`）は OpenStreetMap のデータ（© OpenStreetMap contributors、ODbL）
- 大きな建物（約 1900m² 以上で幅 30m 以上）は L4 の板で立体に、小さな建物は島に濃く刻印、ボーディングブリッジ（84 本）は細い線で刻印
- 縮尺 1:25000（1km = 40mm）。滑走路の幅も実物どおり（60m = 2.4mm）
- 管制塔の模型だけ、見やすいよう高さを約 3 倍にしています

## 大きさ

- 板 272 × 232 mm の島の形（海は島のまわり 6mm だけ。面積は第3版の長方形の約半分 373 cm²。島の大きさは同じ）
- 厚さ 12 mm（ターミナルまで）＋トレーと脚 14 mm ＝ 机から 26 mm。レーダーの上面まで 41 mm

## レーザー加工

| ファイル | 枚数 | 内容 |
| --- | --- | --- |
| L1_底板 | 1 | 土台。LED の足を通す穴（LED のつばは底板の上にのる）、レーダーの穴、ボタンの穴 |
| L2_海の板 | 1 | LED のつばが入る穴、レーダーの穴・ボタンの穴、レーダーを置く位置の線、タイトル・方位・縮尺・凡例の刻印 |
| L3_空港の島 | 1 | 空港の形。LED の穴は Φ6.2（LED は穴に差して、根元を少し接着剤で留める）。滑走路・エプロン・誘導路・滑走路番号の刻印、ターミナルを貼る位置の線、管制塔を差す穴 |
| L4_ターミナルと施設 | 1 | 第1・第2・第3ターミナル（ピアの形まで実物どおり）と、格納庫・整備工場・貨物ビル・立体駐車場 P1〜P5・ホテルなど大きな施設（全 35 個の部品）。L3 に刻印した輪郭線に合わせて貼る |
| L5_タイトル板 | 1 | タイトル・RJTT 1:25000・運用ランプの説明・凡例・縮尺 1 km を彫った小さな板（約 51 × 44 mm）。海の板に刻印した枠に合わせて貼る。運用ランプの LED は板の穴から見える |

配線（5 本）は底板の裏にテープで這わせ、ケースの左の切り欠きから中へ入れます。
運用ボードの ESP32 はレーダーとは完全に別で、自分の USB-C（ケースの右）から給電します。レーダーの ESP32 とは線をつなぎません。

板 1 枚につき SVG（と DXF）が 1 つで、その中で切断と彫刻を分けてあります（イングランドの地図と同じ方式）。
赤の線＝切断、黒の面＝彫刻（濃く）、灰色の面＝彫刻（薄く）。SVG には xTool Creative Space 用の加工の種類（data-processing-type）を付けてあるので、開くと切断・彫刻が自動で入ります。DXF は CUT・ENGRAVE_DARK・ENGRAVE_LIGHT の 3 レイヤー。
用紙はそれぞれの板の大きさ＋余白 3mm です。設定は `laser/加工設定_MDF3mm.md`。

## LED（すべて在庫）

| 場所 | LED |
| --- | --- |
| A 滑走路 16R の端 | 黄・赤 |
| A 滑走路 34L の端 | 緑・赤 |
| B 滑走路 04 / 22 の端 | 赤 / 緑 |
| C 滑走路 16L の端 | 黄・赤 |
| C 滑走路 34R の端 | 2色LEDモジュール（緑/赤）・黄 |
| D 滑走路 05 の端 | 黄・赤 |
| D 滑走路 23 の端 | 2色LEDモジュール（緑/赤） |
| 右上の運用ランプ | RGB LEDモジュール（北風＝青、南風＝橙） |

光の意味：緑＝着陸機が降りてくる端、黄＝離陸機が走り出す端、赤＝飛行機が向かう先の端。
羽田のふだんの運用で、それぞれの端が実際に使われる役割の色だけを置いています。

| 運用 | A | B | C | D |
| --- | --- | --- | --- | --- |
| 北風運用 | 着陸 34L | 使わない（消灯） | 着陸・離陸 34R | 離陸 05 |
| 南風運用 | 離陸 16R | 着陸 22 | 離陸 16L | 着陸 23 |

配線はチャーリープレクシング：ESP32-C3 の 5 本のピン（GPIO3〜7）に 47Ω を 1 本ずつ付け、その 5 本の線を全部の LED に回します。
LED 18 個分（赤5・緑2・黄4・2色2個×2・RGB 3）を 5 本で切り替えられます。

トレーは底を下にして印刷し、上のつばを底板の裏（レーダーの穴の下）にホットボンドで貼ります。USB-C は右の側面から差します（レーダー用）。
ケースは第3版と同じく、上の縁を島の真ん中の下にホットボンドで貼ります。
レーダーのケースは今のものをそのまま使い、裏ぶたは付けません。横のボタン穴は栓を内側から押し込んでふさぎます。

## プログラム（firmware/haneda_board）

- Arduino IDE で `haneda_board.ino` を開く。ボード：ESP32C3 Dev Module、USB CDC On Boot：Enabled
- ライブラリ：ArduinoJson（7.x、レーダーで入れたもの）
- Wi-Fi は `config.h`（レーダーと同じWi-Fi）
- 5 秒ごとに adsb.fi から羽田の周り 12 海里・高度 4000ft 以下の機体を取り、滑走路の延長線上で降りてくる機体を「着陸」、上がっていく機体を「離陸」と判定。最後に見えてから 5 分間その端を光らせる
- 離陸の点滅：高度 2500ft 以下で上昇中、滑走路の延長線上の機体を見つけたら、その機体（ICAO の番号）で 1 回だけ、走り出す端（黄）→ 先の端（赤）を 4 秒間速く点滅。シリアルモニタに「★ 離陸」と便名が出る。データの遅れがあるので、実際の離陸から 5〜15 秒ほど後に光る
- 運用ランプ：青＝北風運用、橙＝南風運用、白＝混在、赤の点滅＝データが取れない
- 本体の BOOT ボタンを押すたびに：自動 → 北風の見本 → 南風の見本 → LED 点検（1 個ずつ順番に光り、シリアルモニタに LED の番号と線が出る）（トレーに入れる前の確認用）
- 電源を入れた直後に全部の LED を 1 回ずつ点ける（配線の確認）

## 配線（wiring/配線図.pdf）

LED は 1〜14 の番号で呼びます（全体図・カード・型紙・電源を入れたときの点検で同じ番号）。5 本の線は 線1〜線5（茶・紫・青・灰・白）。LED と同じ赤・緑・黄の線は使わないので、LED の色と線の色を取り違えません。

1. 全体図：上から見た図。5 本の線の通り道と LED の番号
2. 抵抗基板：ユニバーサル基板 8 × 6 穴に抵抗 5 本
3〜7. 線ごとのつなぐ順番：線1（茶）→ 線2（紫）→ 線3（青）→ 線4（灰）→ 線5（白）の順に 1 本ずつ。ケースの抵抗基板から出て「① No.3 の −（短い足）→ ② No.5 の −（短い足）→ …」と決まった順番に足をつなぐ。区間ごとに切る線の長さ（余裕込み）つき
8〜9. LED ごとのカード：その LED の足（ピン）が、どの色の線につながるか（確かめるとき用）
10. 一覧表と回路のしくみ
11. 底板の裏の型紙：A3 横に 100% で印刷して底板の裏に当てる実寸の型紙（裏から見た向き）
12. レーダーとの合体：トレーの中の並べ方、2 つの ESP32-C3 は別々の USB-C で給電、ボタンの線

電源を入れると LED が 1 → 14 の順に 1 個ずつ光り、シリアルモニタに「確認：No.3 A34L 緑（＋線3 −線1）」のように番号と線が出ます。光らない・色が違う番号の所を見直してください。

## Wi-Fiの設定（GitHubから使う場合）

Wi-Fiの名前とパスワードは公開しないよう、リポジトリには入れていません。
`firmware/haneda_board/config.example.h` をコピーして `config.h` という名前にし、`YOUR_SSID` と `YOUR_PASSWORD` を書き換えてから書き込んでください。

| --- | --- |

| `adsb-radar/case/` | ケースの3Dプリント部品（STL・STEP）と設計スクリプト |
| `adsb-radar/schematic/` | 回路図とユニバーサル基板の配置図 |
| `adsb-radar/images/` | ケースの完成イメージ |
| `adsb-radar/材料リスト.md` | 必要な部品 |

Wi-Fiの名前とパスワードは公開していません。`adsb-radar/firmware/adsb_radar/config.example.h` をコピーして `config.h` という名前にし、書き換えてから書き込んでください。
